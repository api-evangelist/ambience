# Ambience

> Ambience Healthcare builds an AI operating system for healthcare — an ambient
> AI platform for real-time medical encounter transcription, clinical note
> generation, integrated clinical documentation improvement (CDI) with ICD-10
> coding suggestions, and EHR patient-context enrichment across 100+ specialties.
> It integrates with major EHRs (Epic, Oracle Cerner, athenahealth). The
> Integration API is gated: documentation and access are granted on request via
> emr-integration@ambiencehealthcare.com. Backed by a16z and Oak HC/FT.
